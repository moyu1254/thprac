# Discordへのプレイ状況表示

テスト版は `v2.3.1.1-discord-beta.1` です。ZIPを展開し、`thprac.exe`・`thprac32.dll`・`thprac64.dll`を名前を変えずに同じフォルダーに置いてください。バージョン画面には `-discord-beta.1` が付きます。内蔵アップデーターは既存の上流安定版向けのままで、このテスト版の更新通知には使いません。

Discordデスクトップ版を起動し、Discord側でアクティビティ共有を有効にしてから、通常の手順でゲームにthpracを適用します。ゲーム内の状態取得とDiscordへの送信はthpracに組み込まれているため、TouhouStatusの別起動や追加DLLの導入は不要です。ランチャーだけを起動してもプレイ状況は送信しません。

「Discordにプレイ状況を表示」は初期設定でオンです。ランチャーの設定で変更した値は次回の適用時に使われます。適用中はゲーム内F12オプションから切り替えられ、オフにすると表示を解除します。設定は既存の `settings.json` の `discord_presence` に保存します。

## 表示内容と対応範囲

対象バージョンは `thprac_identify.cpp` に適用処理が登録されたものと同じです。ゲームを識別できるだけで適用処理を持たないタイトルやバージョンは含みません。獣王園は1.00a／1.10c、紅魔郷 New Classicは1.03a／1.03bにそれぞれ接続しています。

花映塚ではTouhouStatusと同じく、体力・残機を1P／2Pの行にまとめ、共通欄との重複を避けています。相手スコアとスペル名は表示しません。Discordの各テキスト欄の長さ制限に収まらない場合は、項目の境界を優先して別欄に移し、末尾を省略します。

取得根拠が不足している項目には次の制限があります。

- 妖精大戦争のポーズ／リトライ／リザルトの各サブメニューは、まとめて「メニュー」と表示してプレイ中の数値を消します。ボス／道中の区別も表示しません。
- 黄昏酒場の終了メニューは「リザルト」と表示します。クリア／ゲームオーバーの区別は表示しません。
- ダブルスポイラーは通常プレイとリプレイの区別を表示しません。自機・シーン・撮影数などは取得します。
- 秘封ナイトメアダイアリーは通しScene番号を表示します。曜日名・撮影数・スコア・クリア／失敗の個別判定は表示しません。
- 闇市場の未確認の遷移フラグは表示を解除します。所持カードの一覧、クリア／失敗の個別表示は実装していません。

## 更新と終了

ゲームの描画フックで最大10回／秒の状態取得を行い、Discordの名前付きパイプへの通信は別スレッドで処理します。状態・Stage・残機などの変化を優先し、スコアやカウンターだけの変化は15秒間隔でまとめます。Discordの5回／20秒の制限を守るため、短時間の連続変化は最新の状態にまとめられます。

メニューに戻ると直前のプレイ数値を消します。読み取り失敗、未知の状態、2秒以上更新されない状態ではPresenceを解除します。Discordの終了・再起動時は自動で再接続し、再接続後に取得した状態を送ります。ゲーム終了時はIPC接続が閉じられます。Discord未起動時もゲームの描画スレッドで接続待ちは行いません。

## 自動テスト

Visual StudioのC++ビルドツールと、通常のビルドで生成する `thprac/loc_json.exe` が必要です。リポジトリルートで次を実行します。

```powershell
./tests/run-discord-tests.ps1
```

適用対象の登録漏れ、32／64ビット共通フォーマッター、模擬IPCでのREADY・ACK・切断・再接続・解除、各作品のメモリー読み取りと状態判定を確認します。テストのIPC名は実際のDiscord用パイプと分けられており、実アカウントの表示を変更しません。CIでも同じテストを実行します。

これらは合成メモリーと模擬IPCによる検証です。全23作品の実機プレイ、実際のDiscordクライアントでの表示、Wine／Steam DeckのIPCは未検証です。

2026-10-15のローカル検証では、Visual Studio 2022のv143を指定したReleaseビルドと上記の一括テストが成功しました。登録チェックは25バージョン／23作品、後半作品の取得テストは144項目、Scene系4作品は31項目です。共通IPCと初期作品の取得処理はx86／x64の両方で確認しています。配布版のCI結果とビルド情報はリリースページと同梱の `BUILD.json` で確認できます。
